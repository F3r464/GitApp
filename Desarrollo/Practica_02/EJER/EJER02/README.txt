TENSURA — SITIO WEB DE 3 PÁGINAS

Estructura:
- index.html       -> página principal
- guerra.html      -> información de la Guerra Tenma
- personajes.html  -> personajes y facciones
- css/estilos.css  -> estilos compartidos
- js/menu.js       -> menú responsive

PASO 2:
El sitio utiliza CSS Grid, Flexbox y media queries para escritorio,
tablet y teléfono móvil.

La versión está preparada para seguir mejorándose en los siguientes pasos:
- Paso 3: animaciones, transition y @keyframes.
- Paso 4: mejoras de accesibilidad.
- Paso 5: selectores avanzados y recreación de un diseño de referencia.
